## 2. 任务定义层经验（taps["任务列表"]）

### 2.1 任务列表的本质

任务列表是**调度队列**而非简单清单：
- 每条条目 = `{任务名, 超时, ff, 任务参数9槽位, ...特征行参数}`，框架按任务名查找同名模块执行
- 条目出现顺序 = 执行顺序，**同名条目重复出现是刻意设计**（锚点任务穿插：每 5-6 条插一次"打野/是否在城外"，表达执行节奏，**不得按名去重**）
- 同名双区间条目 = 条件分支表（框架对同名任务取**末条**生效，FrameRun.lua）
- 注释掉的条目 = 带执行条件的"功能开关库存"（应映射为 enabled=false 而非丢弃）

### 2.2 任务参数 9 槽位权威语义

```
任务参数 = (启动方法, 执行方法, 执行模式, 执行间隔时间, 进入任务超时时间,
           是否有对应设置, 执行次数, UIID, 任务执行前操作)
```

| 槽位 | 语义 | 实测用法 |
|:----:|------|---------|
| 1 | 启动方法 | 恒 0（未见实际使用） |
| 2 | 执行方法 | **核心复用机制**：非 null 时多任务名共享同一执行模块（升级铁匠铺/市场/大使馆→"普通升级"；四兵种→"造兵"；4 任务共用"造兵通用"） |
| 3 | 执行模式 | 少用 |
| 4 | 执行间隔时间 | **秒级冷却**，支持表达式 `60*60*2`、`60*60*24/ReadUIConfig("运输次数")`、哨兵 "M" |
| 5 | 进入任务超时时间 | 毫秒 |
| 6 | 是否有对应设置 | bool |
| 7 | 执行次数 | 少用（用 outCount/循环次数代替） |
| 8 | UIID | 少用 |
| 9 | 任务执行前操作 | **前置钩子**：执行任务前先跳转的模块/函数（"队列检测"、"变量归位"、"出城回城"、"定位主城"） |

### 2.3 条目两种形态（编译器分派依据）

- `ff="nil"`：纯调度条目，**必须有同名模块**（否则调度落空——真实脚本存在此 bug，需静态校验）
- `ff=识别指令`（ps/p/ft...）：条目自带入口特征 = 自足式轻量任务，无需建模块（黎明之战大量使用此方式把"定位类任务"降级为条目级特征，模块数 39→23 收敛）

### 2.4 条目写法演进（早期 → 成熟）

1. 静态直写 `taps["任务列表"][N]=` → 2. `Dim task` 别名 + `task(UBOUND(task)+1)` 动态追加（可在条目间嵌 If 按配置切任务）→ 3. `任务参数设置(...)` 函数包装 → 4. `array(...)` 字面量 + 文件头注释槽位语义

## 3. 模块拆分层经验

### 3.1 模块四类体系（大型脚本稳定结构）

| 类别 | 典型模块 | 职责 |
|------|---------|------|
| 登录链 | 进入游戏→选区→登录游戏（含渠道分发器、验证滑动） | 启动/切号 |
| 弹窗体系 | 弹窗检测 / 通用弹窗 / 渠道弹窗 / 验证弹窗 | 异常恢复（见 §5） |
| 通用工具 | 通用任务退出 / 点击检查 / 回收检测 / 使用道具 / 立即使用 / 获得奖励 | 被链式复用的公共动作 |
| 任务模块 | 每个任务列表条目对应的业务模块链 | 业务流程 |

### 3.2 拆分粒度经验

- **模块 = 一个界面状态**，特征行 = 该状态下的一个动作；模块链 = 界面切换序列
- 链深实测上限约 7 跳；过深时用**参数化调用**收敛（见 §4.4）
- 同构重复模块两种收敛范式：**参数化**（10 个方向滑动模块 → 1 个带参模块）与 **大分发器路由**（50 特征单模块按执行条件分派）
- 模块是**热替换单元**：改版脚本只需重写对应模块（QYJ_NEW/HD_NEW 只改 getTaps()），编译器应支持模块级差异补丁
- 锚点任务穿插：把"回主界面校准"类任务重复插入任务列表，是长流程防漂移的关键手段

### 3.3 模块声明三件套（按键版方言）

```vb
taps["模块名"] = Array()          ' 声明
taps["模块名"]["超时时间"] = 300    ' 模块级配置（scalar 行为主，[0] 配置行是文档写法、真实脚本 0 例）
Dim 模块名 = taps["模块名"]        ' 别名
模块名(UBOUND(模块名)+1) = {...}   ' 追加特征行
taps["模块名"]["name"] = "模块名"  ' 自描述（成熟版标配）
```

两种写法语义等价可折叠：scalar 配置行 ≈ `[0]` 配置行；`别名(UBOUND+1)` ≈ `taps["X"][N]=`。

### 3.4 模块级配置取值惯例

| 配置 | 惯例值 |
|------|--------|
| 超时时间 | 秒；长流程 180-300，战斗 90-120；**可为变量引用** `array(1,"任务变量",键)`；90 小时这类超长超时形同虚设（反例） |
| 循环次数 | 常量或变量名（"巨兽个数"）；环状互跳必须靠 `循环次数>1` + outCode 限次破环 |
| 无特征次数 | 防卡死兜底，配合 `无特征运行` 指向补救模块 |
| 超时方法 | 三级兜底的最后一级；可自引用（`卡屏不退=true` 形成受控长挂环）或指向补救模块 |
| 退出方法 | 退出后收口（默认"通用任务退出"，实测 129 处引用 + 20 种业务退出） |
| 任务界面 | 进入模块的前置界面校验（waitOut 配套）；空 `任务界面=Array()` 是无效占位（55 处，反例） |
| outCount | 连续检测到特征 N 次后退出；**可动态化** `outCount=array(1,"任务变量","打野次数")` + 条目变量清零 |
| 强制休息 | 每轮循环休息 ms，防手速检测 |
| 截图至内存 | 弹窗模块标配（循环次数=1 + 截图至内存） |

## 4. 流程控制层经验

### 4.1 跳转三路语义（一条特征可同时挂）

| 字段 | 语义 | 用法 |
|------|------|------|
| `运行后方法` | 成功链 | 找到特征并执行后跳转 |
| `notFun` | 失败备胎 | 未找到特征时转指定模块（**隐式调用**：静态入度 0 不代表死代码） |
| `out` / `notOut` / `outTast`(拼写) / `outCode` | 终止链 | 找到/未找到时退出模块；outCode 带返回码（如 66） |

### 4.2 执行条件（五形态，模块级与特征级同构）

1. 数组形 `[作用域, "表", "键", op, 值]`（作用域 1=vars 156 处 / 3=config 55 / 2=conf 31 / 7=readUI 15）
2. 与或组合 `array("or", ...)` 嵌套
3. 命名条件字符串（指向 Function，如 "taskcheck"、"Battlefield"）
4. ReadUIConfig 表达式
5. 裸字符串/任意表达式（7 天冷却 `getTime-fileGetUser(...)>=7*86400`）

### 4.3 幂等/冷却惯用法

`执行条件 X~='1'` + `变量赋值 X='1'` 成对出现 → "仅执行一次"语义；可映射为编译器一等公民节点。

### 4.4 参数化调用（框架唯一"带参调用"）

`变量赋值(true, Array(键,值,...))` + `运行后方法="目标模块"` = 跳转前赋值序列（如 制造丧尸→造兵招募 传 `造兵=1, 造兵种类=丧尸`）。编译器应生成"跳转前赋值"而非复制实现。

### 4.5 同名特征多行 = if/elif 阶梯

同一模块内同名特征多行、各挂不同执行条件（巨兽"出征[1..4]"）；优先级数字越小越优先（1 先试，9 兜底）。

## 5. 防卡死与异常处理模板（三件套，8/9 脚本高度一致，可内置化）

```
弹窗检测        —— 检测线程轮询，发现弹窗置 vars 标记
通用弹窗        —— 循环次数=1 + 截图至内存；按弹窗类型 out+运行后方法
                   跳回被打断的任务模块（"关闭即恢复现场"）
通用任务退出    —— 回到主界面锚点（out=true）+ notFun=通用弹窗
```

配套机制：
- `检测线程` + conf 卡屏检测参数（卡屏阈值/无特征阈值）
- 退出方法族两级收口：框架契约模块（通用任务退出）→ 领域模块（`X退出`）
- **通用任务退出必须保持纯净**（反例：ZHG_01 把业务动作写进通用任务退出，129 处引用面被污染）
- "立即使用/获得奖励"类确认弹窗应一等化为公共模块（立即使用入度 20）

## 7. 坑与反例清单（真实脚本中实际存在）

1. **调度必失败**：神途"打野"、龙迹之城"天空禁地2"、简游黎明"治疗帮助"任务条目无同名模块（ff=nil 落空）
2. **键名笔误静默失效**：`"wait:"`（应为 wait）、`推出方法`、`aterTape`、`强制修仙`（应为强制休息）
3. **拼写二相性**：outTast/outTask、ForCheck/forCheck、array/Array —— 解析需归一
4. **90 小时超时**形同虚设；空 `任务界面=Array()` 55 处无效占位
5. **GBK 字符串内 `//`** 注释截断风险
6. **通用任务退出被业务污染**（ZHG_01）：公共模块必须保持单一职责
7. **配置键漂移**：`超时退出` vs `超时时间` —— 同义键名归一
8. 完全无 taps 的过程式脚本路线也存在（新建脚本 c649：UI+卡密+startX），不是本工具目标形态
