## 1. 总体路线图

```
P0 环境准备 ──▶ P1 核心脚本 ──▶ P2 Trae 集成 ──▶ P3 端到端
(3天)          (2周)          (3天)          (1周)
  │              │              │              │
  ▼              ▼              ▼              ▼
环境检查       adb+feature    rules+soul     完整流程跑通
锚点公式       analyze+coord  知识库索引      编译输出验证
               compile
```

| 阶段 | 名称 | 周期 | 核心交付 |
|------|------|------|---------|
| P0 | 环境准备 | 3 天 | 环境检查通过 + 锚点公式确认 |
| P1 | 核心脚本 | 2 周 | 6 个脚本全部可运行 |
| P2 | Trae 集成 | 3 天 | rules.md + soul.md + 知识库索引 |
| P3 | 端到端测试 | 1 周 | 完整流程跑通 + 脚本编译验证 |

**总计：约 4 周**（独立开发方案需 14 周，节省 70%）

## 2. P0：环境准备（第 1-3 天）

### 2.1 目标

确认开发环境可用，解除唯一硬阻塞（锚点换算公式）。

### 2.2 任务拆解

| 编号 | 任务 | 优先级 | 预估 | 依赖 |
|------|------|:------:|------|------|
| P0-01 | Python 环境检查：版本、依赖包安装 | 高 | 0.5天 | - |
| P0-02 | ADB 检查：路径、模拟器连接、截图测试 | 高 | 0.5天 | - |
| P0-03 | LLM API 检查：key 配置、视觉模型调用测试 | 高 | 0.5天 | - |
| P0-04 | ~~读 jy-frame-engine 源码定位锚点换算公式~~ **已确认：九宫格锚点系统（1-9）** | ✅ | - | - |
| P0-05 | 锚点换算实现：9 种锚点双向换算 + 自动判断 | 高 | 1天 | P0-04 |

### 2.3 验收标准

- [ ] `python --version` >= 3.11
- [ ] `pip list` 包含 Pillow, numpy, opencv-python, rapidocr-onnxruntime, jinja2, pyyaml
- [ ] `adb devices` 至少一个设备在线
- [ ] `adb exec-out screencap -p` 能保存截图
- [ ] 视觉 LLM API 能返回正常响应
- [ ] 锚点换算公式已确认（九宫格 1-9），coordinate.py 实现 9 种锚点双向换算
- [ ] 锚点换算测试用例通过（9 种锚点 + 跨分辨率）

### 2.4 关键风险

| 风险 | 影响 | 应对 |
|------|------|------|
| 锚点公式在源码中不明确 | 坐标全错 | 优先 P0-04，必要时逆向或联系框架作者 |
| 视觉 LLM API 不可用 | 感知层无法工作 | 准备备用模型（Qwen-VL / 本地模型） |

## 8. 依赖与风险

### 8.1 外部依赖

| 依赖 | 用途 | 风险 |
|------|------|------|
| JY-Frame 源码 | 锚点换算公式 | 公式不明确则需逆向 |
| 视觉 LLM API | 界面分析 | 成本/稳定性/速率限制 |
| ADB | 设备操作 | 模拟器兼容性 |
| RapidOCR | 文字识别 | 小字/艺术字识别率 |
| Trae | AI 宿主 | 规则加载机制可能变化 |

### 8.2 技术风险

| 风险 | 概率 | 影响 | 应对 |
|------|:----:|:----:|------|
| 锚点公式复杂 | 中 | 高 | P0 优先确认，写对比测试 |
| 自动取色点不稳定 | 中 | 高 | 多帧验证 + 自动换点 + 偏色自适应 |
| 视觉模型识别不准 | 中 | 高 | OCR 融合 + 低置信度重试 |
| AI 调度不按规则 | 低 | 中 | rules.md 写明确 + 关键步骤强制检查 |
| 编译脚本与 AI 行为不一致 | 中 | 高 | 编译后必须在设备上回归测试 |

### 8.3 缓解策略

- 每个阶段结束有明确验收，不达标不进入下一阶段
- 核心函数有单元测试
- 每次运行保存完整截图和 JSON，可回溯
- 视觉模型调用加缓存，相同截图不重复调用
- 锚点换算有独立测试用例，与框架行为对比
