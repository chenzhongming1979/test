### 2.4 三个最复杂任务链深剖

#### 深剖① 王城"章节任务"链（练号主线，约 40 模块参与）

```vb
// HJG_WC.mq:1984-1995

taps["章节任务"]["执行条件"] = array(ReadUIConfig("练号") = true,array(1,"状态变量","当前章节","<",8))
taps["章节任务"]["ForCheck"] = false            // 关闭超时/循环检查——整条主线长期运行

章节任务(UBound(章节任务)+1) = {"主界面",5,"ff":"ps","notFun":"通用弹窗","运行后方法":"点击章节",...}
```

### 3.3 复用模式

1. **框架契约模块 + 游戏定制**：`通用任务退出`/`通用弹窗`/`检测线程` 三件套每文件必有，但行内容按游戏 UI 定制（doc-27 语义在真实脚本中的落地形态，见深剖①）。
2. **领域退出族**：每个业务域（军团/战役/增益/巨兽/奖励/狩猎/英雄）一个 `X退出`，其内部再 `运行后方法→通用任务退出` 收口——两级退出。
3. **状态归位层**：`出城回城`（猿族，ty 状态机）、`城内归位`、`变量归位`（巨兽，slot9 前置）、`复位`（王城，来自框架库）——"退出后回到可预测状态"。
4. **恭喜/获得物品 单行领取器**：猿族"恭喜"（超时时间=3，1 行）被 14+ 个活动模块 `运行后方法` 复用；巨兽"获得物品"（超时15）被 20+ 处复用——**最热的复用模块反而最小**。
5. **中枢路由**：王城"前往检查"(34行)/猿族"章节任务弹窗"(49行)/"任务识别"(25行)/巨兽"收取资源判断"(10行)——识别当前界面可做的事，逐行 `运行后方法` 分发；未命中走 `notFun→上级弹窗`。
6. **跨文件复用**：`复位/任务参数设置/变量赋值/loginBack/ipCheck/clickRandom/runCheck/getCardID` 等在 `runFun.mql/HJG.lua`（Import）中定义，`notFun:"复位"` 可指向框架库模块——引用解析必须跨 Import。

## 5 坑与反例

1. **没有 [0] 配置行**：文档示例用 `taps["M"][0]={"超时时间":...}`，本批 3 文件 0 例。编译器若只支持 [0] 形态将解析不到任何配置。
2. **键名别名/脏数据**：`zxtj`=执行条件（猿族 89 处）；scalar 键带前导空格（`taps["X"][ "退出方法"]`，王城 11 处）；`ForCheck` 大小写混用。键匹配必须 trim+别名表。
3. **指令拼写漂移**：`tmove`(文档 tMove)、`fts`/`psw`（疑为 ft_s/ps_w 漏下划线）、`ps_l`、`ft_ex_f`、`ff:"fun"`——指令表需容错登记。
4. **一行多语句**：存在两条赋值挤在一行（猿族 L628 附近"对话/幸存者对话"），按行 split 会漏；必须括号配对解析（本分析用 brace-matching 解决）。
5. **注释语句仍命中正则**：`//task(UBound(task)+1)=...` 16 条注释任务与活动条目混排，且 `//taps["绝地寻宝"][2]` 会覆盖同索引活动行——解析必须判断行首注释，索引覆盖需按"最后一次有效赋值"处理。
6. **同名覆盖/重复键**：猿族"通用"字典"城内/城外"各定义 2 次不同 p（L623/637、624/638），后者覆盖前者；王城进入游戏 L475 一行出现两个 `"变量赋值"` 键。迁移时后者生效，需告警。
7. **引用目标不在本文件**：`notFun:"复位"`、`任务参数设置()`、`变量赋值()`、`outCode:66→ipCheck` 等指向 Import 的 runFun.mql/HJG.lua；**王城全文件搜不到 `复位` 定义**。静态校验必须跨 Import，否则误报悬空引用（本批引用图中 复位/runCheck/levelSel/noTeam/moveBB/tianfu 等均为外部目标）。
8. **`任务界面=Array()` 语义不明**：44~49 处模块把任务界面设为空数组（王城关卡挑战还配 `waitOut=6000`），与打野的 `任务界面[1]={特征行}` 行为差异无法从脚本侧确认——需对照框架 TaskScheduler 源码验证空数组的等待语义，编译器先按"无门槛"处理并留探针。
9. **第2槽位语义冲突**：框架文档叫"优先级"，运行时示例映射 `timeout:5`。本批几乎全为 5，说明作者把它当"默认超时"用；个别 9/8/7（回城/跳过/对话）更像权重。映射时建议按"特征检测超时秒"实现，兼容 -1。
10. **巨型中枢模块**：前往检查 34 行、章节任务弹窗 49 行、通用弹窗 57 行——单模块超 30 行即路由表，按线性流程编译会产生错误的顺序语义（应编译为"优先级有序的识别-分发表"）。
11. **test 残留**：猿族 L3435 `conf["游戏模式"]= 7`（超出文档 1~5 定义）与"测试"模块、王城"开始扫荡退出"空模块、`LNone 巨兽退出(1c)` 全注释模块——生产脚本里混有调试死代码，统计与校验要区分"声明未用"与"注释残骸"。
12. **数据自相矛盾的配置**：王城"收集资源退出"循环1+退出方法双配；"装备自选箱" `循环次数=1` scalar 写两遍（L1212）——重复配置静默覆盖。
13. **奖励红点轮询依赖固定坐标**：任务奖励×3 条目的 `p` 是三个红点位置硬编码，UI 改版即失效；新编译器应鼓励"区域内找色"替代绝对点。
