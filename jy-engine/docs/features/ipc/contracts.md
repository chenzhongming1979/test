# 跨进程通道契约

> 文档版本 v1.0（2026-09-18，文档三层化重组新建）
> 本域权威范围：ipc 域七条跨进程/权限通道的可观察契约（帧格式、序列化约束、接口签名、事件结构、降级语义），每条句末标注对码基准。

## ① stdin/stdout 帧协议（app ↔ root RPC 载体）

- 帧格式：`MESSAGE_HEADER("<AutoLua>") + 4 字节大端 int 载荷长度 + 载荷`，帧头定长 13 字节（`MESSAGE_HEADER_LENGTH = MESSAGE_HEADER.length + 4`）；编码侧 `packageData` 按 `ByteOrder.BIG_ENDIAN` 组帧（`autolua2\engine\src\main\java\com\autolua\engine\core\root\TransportImp.kt:196`、`TransportImp.kt:197`、`TransportImp.kt:200`）。
- 管道流向：app 侧以 `TransportImp(process.errorStream, process.outputStream)` 构造（读=root 的 stderr、写=root 的 stdin），root 侧以 `TransportImp(System.in, System.err, true)` 构造——**帧协议实际走 root 视角的 stdin/stderr 对**，root 的 stdout 是纯文本日志流，由 app 侧独立 Scanner 线程读取转 logcat，不参与帧协议（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:119`、`autolua2\engine\src\main\java\com\autolua\engine\core\root\Server.kt:23`、`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:187`）。
- 解码状态机：`DecodeState.UNKNOWN / MESSAGE` 两态——UNKNOWN 态逐字节扫描，遇到帧头进入 MESSAGE 态，遇 `\n` 则把扫过的字节按"其他消息"（文本行）回调 `onOtherMessage`（root 打进 stderr 的非帧日志由此分帧）；MESSAGE 态等待头+size 字节齐全后整帧交付（`autolua2\engine\src\main\java\com\autolua\engine\core\root\TransportImp.kt:35`、`TransportImp.kt:54`、`TransportImp.kt:45`）。
- 读写模型：发送经 `LinkedBlockingQueue` 排队由独立写线程刷出（`send` 入队、`onWrite` 消费）；读线程解析出整帧后派发 `onMessage`（`autolua2\engine\src\main\java\com\autolua\engine\core\root\TransportImp.kt:209`、`TransportImp.kt:112`、`TransportImp.kt:173`）。
- 派发纪律：`isServer=true`（root 侧）收到的请求用 2 线程池并发处理（execute 等长任务会占住一个处理线程）；app 侧必须顺序处理——并发派发会导致 WS 日志帧乱序、双线程同时阻塞在广播上拖垮读线程、进程管道积压后反向卡死 root 的写线程（`autolua2\engine\src\main\java\com\autolua\engine\core\root\TransportImp.kt:173`，注释见 `TransportImp.kt:183`）。
- 握手与退出：`rawWrite`/`rawRead` 绕过队列直读直写，用于启动握手（init 包、"ok"/"abort"）与销毁时等待 "exit"（`autolua2\engine\src\main\java\com\autolua\engine\core\root\TransportImp.kt:225`、`Client.kt:317`、`Server.kt:36`）。

## ② Parcel / InvokePackage 序列化约束

- 调用包：`InvokePackage(serviceId:UInt, callId:Int, method:String, args:Array<out Any>?)`，`@Parcelize` Parcelable，args 为 null 表示无参调用（`autolua2\engine\src\main\java\com\autolua\engine\core\root\InvokePackage.kt:8`、`Server.kt:68`）。
- 保留 serviceId：`OBSERVER=1u`、`CODE_PROVIDER=2u`、`RESOURCE_PROVIDER=3u` 为两端约定的固定服务号，不可挪用（`autolua2\engine\src\main\java\com\autolua\engine\core\root\InvokePackage.kt:28`）。
- 帧内首字节 type：请求帧 `writeByte(1)` 后 `writeValue(InvokePackage)`；响应帧 `writeByte(2)` 后 `writeInt(callId)`；type 非 1 时按回调处理——读 `parcel.readInt()` 得 callId 再 `dataCallbackManager.notify`（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:296`、`Server.kt:59`、`Client.kt:205`、`Server.kt:98`）。
- 响应体：`writeByte(2) + writeInt(callId) + writeNoException()/writeException(e) + writeValue(result)`；跨进程异常必须是 Parcelable，否则包成 RuntimeException 再写（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Server.kt:58`、`Server.kt:72`）。
- 接口返回值特殊编码：方法返回类型是接口时，服务端把返回对象注册进本地 ServiceManager 并回写 `Long` 型新 serviceId，客户端按 id 重建远程代理（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Server.kt:257`、`Client.kt:263`）。
- Release 语义：`Releasable.release` 方法名特殊处理——app 侧服务收到该调用且不在持久名单时自注销，root 侧反射调用实例的 release（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:251`）。
- 初始化包：握手时 app 侧按 environments → localServices → remoteServices 三次 `writeValue` marshall 一次性写入，root 侧 `rawRead` 后同序反序列化（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:123`、`Server.kt:126`）。
- 回包匹配：`DataCallbackManager<T>` 以 AtomicInteger 自增 callId 登记 waiter，`waitAndRemote(id, timeout)` 同步等 notify；notify 时有 callback 走回调、无 callback 置数据并唤醒（`autolua2\engine\src\main\java\com\autolua\engine\core\root\DataCallbackManager.java:37`、`DataCallbackManager.java:54`、`DataCallbackManager.java:77`）。

## ③ 本地服务注册协议（pushLocalServices 服务名清单）

- 注册模型：app 侧 `Builder.addLocalService` 把实例登记进 app 进程 `ServiceManagerImp`（自增 UInt 服务号，0 保留），并生成 `LocalService(name, interfaceName, serviceId|className)` Parcelable 随初始化包下发；root 侧 `serviceInfo2LocalService` 按有 serviceId → 远程动态代理、有 className → 本地 Class 反射实例两种方式还原（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:50`、`autolua2\engine\src\main\java\com\autolua\engine\core\root\ServiceManagerImp.kt:17`、`Client.kt:26`、`Server.kt:103`）。
- 预注册三固定服务：Builder 构造时即登记 CODE_PROVIDER / RESOURCE_PROVIDER / OBSERVER（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Client.kt:40`）。
- app 进程注入的服务（root 经远程代理反向调用）：`UI`、`FloatController`、`IdeLog`、`uimgr`（`autolua2\app\src\main\java\com\autolua\autolua2\MainApp.kt:112`、`MainApp.kt:118`）。
- root 进程本地注册的服务（实例在 Lua 同进程，Lua 全局名同名）：`http`、`luajava`、`LuaEngine`、`file`、`device`、`crypt`、`app`、`plugin`、`ocr`、`media`、`ime`、`mysql`、`event`、`compat`（必须最后注册，依赖前序服务）、`uilib`（`autolua2\engine\src\main\java\com\autolua\engine\core\root\Server.kt:146`、`Server.kt:190`、`Server.kt:193`）。
- Lua 注入时序：`AutoLuaEngineOnLocal.pushLocalServices` 在原生图色函数注入完成后的 `postNativeInject` 回调里执行——wrapLocalService → `luaContext.setGlobal(服务名)` → 若实例实现 `LuaEnvContributor` 则 `contribute(ctx)` 自注册全局函数（`autolua2\engine\src\main\java\com\autolua\engine\core\AutoLuaEngineOnLocal.kt:206`、`AutoLuaEngineOnLocal.kt:256`）。
- IDE 沙箱同款注入：`LuaEngineExecutor.registerService` 平行注册同一批服务名（含 `uimgr`/`uilib`），保证脚本在两环境可移植（`autolua2\app\src\main\java\com\autolua\autolua2\MainApp.kt:163`）。

## ④ pollEvents JSON 事件结构（UI 事件轮询通道）

- 拉取接口：`IUiMgr.pollEvents(): String`——事件队列空返回字面量 `"[]"`；非空一次性排空 `ConcurrentLinkedQueue`，逐条还原为 JSONObject 拼 JSONArray 返回（`autolua2\app\src\main\java\com\autolua\autolua2\extension\ui\UiMgrImp.kt:80`）。
- 队列容量：`MAX_EVENTS = 256`，入队时超限丢弃最旧一条（`autolua2\app\src\main\java\com\autolua\autolua2\extension\ui\UiMgrImp.kt:42`、`UiMgrImp.kt:75`）。
- UI 控件事件帧：`{"ev":"ui","win":<winId>,"id":<ctrlId 可缺省>,"event":<事件名>,"data":<负载 JSONObject 可缺省>}`，由控件 listener 回调 `emitOf(win)` 统一组帧（`autolua2\app\src\main\java\com\autolua\autolua2\extension\ui\UiMgrImp.kt:65`）。
- 弹窗结果事件帧：`{"ev":"dialog","req":<n>,"action":"ok|cancel|select|...","values":{...},"index":<n 仅 sheet>}`，弹窗名约定 `"__dlg_<req>"`（`autolua2\app\src\main\java\com\autolua\autolua2\extension\ui\UiMgrImp.kt:282`、`UiMgrImp.kt:262`）。
- op 协议响应帧：`{"req":<原样带回 可缺省>,"ok":bool,"data":{...} 成功时,"err":"..." 失败时}`，op 同步执行主线程落点 + 8s 超时（`autolua2\app\src\main\java\com\autolua\autolua2\extension\ui\UiMgrImp.kt:119`、`UiMgrImp.kt:112`）。
- Lua 侧路由键：UI 事件按 `win\1id\1event` 三元组匹配 `ui.bind` 注册表；dialog 事件按 `tostring(req)` 匹配等待者/异步回调（`autolua2\engine\src\main\java\com\autolua\engine\extension\ui\UiLib.kt:84`、`UiLib.kt:70`）。

## ⑤ IInjectChannel 接口签名与三通道降级语义

- 通道接口：`start()/stop()/isAvailable()/name()` + `injectDown/injectMove/injectUp(pointerId,x,y,downTime)` + `tap/swipe/pinch/gestureJson` + `default injectKey(keycode)`（仅 DIRECT_ROOT/ROOT 实现，无能力通道返回 false 由门面降级）（`autolua2\engine\src\main\java\com\autolua\engine\input\inject\IInjectChannel.java:17`、`IInjectChannel.java:35`、`IInjectChannel.java:70`）。

## ⑥ AIDL AuxDumpService 接口

## ⑦ 共享内存帧协议（seqlock A/B 双缓冲，与 cpp SharedFrame 对码）

- 内存布局：两块 `MemoryFile`（`autolua_shot_a` / `autolua_shot_b`），单块尺寸 `width*height*4 + HEADER_SIZE(9)`；9 字节自描述头为 `[0]=bufferIndex(byte)`、`[1..4]=width(int BE)`、`[5..8]=height(int BE)`，像素自第 9 字节偏移起（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:29`、`SharedMemoryManager.java:112`、`SharedMemoryManager.java:32`）。
- seqlock 写协议：整帧写入当前缓冲 → `frameCounter.incrementAndGet()` **写后置**，偶数表示写完成；读侧读前读后两次取 counter，不一致则整帧作废重读，最多 `READ_RETRY = 8` 次（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:282`、`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\FrameBuffer.java:40`、`FrameBuffer.java:15`）。
- ping-pong 写协议（writeFrameSwap）：写 inactive 块 → counter++ → 9 字节自描述头同步写两块（putInt 默认大端）；读侧以 `readBufferIndex` 翻转（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:314`、`SharedMemoryManager.java:324`、`SharedMemoryManager.java:325`）。
- C++ 读侧对码：`SharedFrame::setSharedMemoryInfo(addrA, addrB, size, w, h)` 接收 Java `init()` 成功后经 JNI 下沉的 mmap 基址；`SharedFrame::getFrameCounter(env)` 经 JNI 回调 Java `getFrameCounter()`（env 为空时返回缓存值）——与 Java 侧 `nativeSetSharedMemoryInfo` / `nativeGetFrameCounter` 静态注册一一对应（`autolua2\engine\src\main\cpp\extension\SharedFrame.h:16`、`SharedFrame.h:31`、`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:429`）。
- fd 跨进程传递：`getFds()` 返回 `[fdA, fdB]`（fd 经反射 `MemoryFile.getFileDescriptor` + `FileDescriptor.descriptor` 提取），上层经 AIDL 附带传递后对端 mmap（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:221`、`SharedMemoryManager.java:237`）。
- 帧计数权威：`frameCounter`（AtomicLong）为 seqlock/ping-pong 两协议共用唯一计数器，Lua/Java/C++ 三侧同协议读（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:75`、`SharedFrame.h:28`）。
- 沙箱读侧消费端（虚拟屏任务书 §2）：`SharedMemoryDisplay`（`autolua2\engine\src\main\java\com\autolua\engine\extension\display\SharedMemoryDisplay.java:30`）把共享内存帧适配成引擎 Display 接口——update() seqlock 读协议：读前读后两次取 frameCounter（`SharedMemoryDisplay.java:119`、`:154`），不一致（`:155`）或 Root seqlock 奇数写中（`:126`）则整帧作废重读（READ_RETRY=8，`SharedMemoryDisplay.java:35`）；ping-pong 读 `readBufferIndex` 发布块并校验 9 字节头 `[0]==块下标` 与 `w*h*4+9 ≤ size`（`:149`），锁定"最近一次写完成"的块后经 `duplicate().position(HEADER_SIZE).slice()` 暴露像素起点 DirectByteBuffer（`:165-166`，零拷贝，C++ GetDirectBufferAddress 直读），块映射经 `SharedMemoryManager.getBuffer(index)` 取（`autolua2\engine\src\main\java\com\autolua\engine\display\sharedmem\SharedMemoryManager.java:399`）；读不到帧保持上一帧视图不阻塞不抛异常（hasRealFrame=false）；CaptureScreenService 停止/重授权致 init 重入时按地址/尺寸快照失效重拉映射。装配契约见 ../engine-core/contracts.md §1（条件 = `CaptureScreenService.isRunning()`，否则 EmptyDisplay 回退）。
- 虚拟屏按屏帧泵（虚拟屏任务书 §4.4，第二批新增）：主屏单例 `SharedMemoryManager` 之外，每个 Shizuku 虚拟屏在 UserService 服务进程持有**独立的一组 A/B MemoryFile**（ashmem 名 `autolua_vd_<displayId>_a/_b`，单块尺寸同 `w*h*4+9`、9 字节自描述头布局同 §⑦，懒建于首次 attachFrameSink；`ShizukuUserServiceMain.java:831` ensureSinkFiles）——不与主屏单例共享实例/命名，≥2 虚拟屏并行互不串扰。

- 虚拟屏帧泵读侧（跨进程 seqlock）：客户端 `VdFrameClient`（`autolua2\engine\src\main\java\com\autolua\engine\extension\virtualdisplay\VdFrameClient.java:27`）attach 时收 `attachFrameSink` 返回的 fd（binder 传输已 dup 至客户端进程，PFD 引用须与 mmap 同生命周期）→ `SharedMemoryManager.mapFdToByteBuffer` native 映射（public 复用，`SharedMemoryManager.java:445`）→ getFrame()：AIDL 轮询 counter（两次/帧）→ 偶数 → 校验 9 字节头（bufferIndex/w/h）→ 拷贝像素区 w*h*4 → counter 前后一致才交付，重试 ≤8 次（对齐 READ_RETRY）；counter=0（从未出帧）或校验失败返回 null。与 §⑦ 读协议同语义，差异仅在 counter 读走 binder（写侧在另一进程）。
