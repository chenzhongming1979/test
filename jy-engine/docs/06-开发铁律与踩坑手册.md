# 开发注意事项：踩坑手册与已知问题

> 文档版本：v1.0（2026-09-14）
> 定位：改动引擎前**必读**。收录的是框架级陷阱（违反即崩溃/静默失效）、已知限制与未完成事项。
> 构建工具链坑在 [05-构建与自测指南.md](05-构建与自测指南.md) §5，不在此重复。

## 1. Lua-Java 桥接层陷阱（改桥接层必读）

1. **LuaContextImplement 类型读取对 nil/类型不符直接抛 LuaTypeError**：`toString()/toLong()` 遇 nil 抛 `exception type string now type nil`，且该异常在 group pcall 内表现为**静默中断**（无输出）。
   → 可选参数一律先 `L.type(i) == ValueType.STRING/NUMBER` 判型再读（optStr/optInt 模式）；`L.top` 是**属性**不是方法。
2. **table2Map/table2Java/table2List 相对索引 bug（已修，勿回退）**：遍历中 pushNil/pop 移栈后 `-1` 相对索引失效，嵌套表（如 `http.request` 的 options.headers）转换 SIGSEGV。
   → 一律用 `absIdx(getTop + index + 1)` 归一化绝对索引。单层表测试测不出此雷。
3. **LuaObjectAdapter 方法调用双闸门**：`nd:click()` 这类方法调用**先经 index() 判名，动作方法名必须在 index() 返回 2 才会 pushcclosure 生成方法闭包**，然后 call(L, name) 才被分发。
   → 新增可调用方法必须 index()、call() 两处同步加分支；只加 call() 会得到"看似注册实际 nil"。
   → 自测注意：适配器属性 index 返回 userdata，别用 `checkType(x,"function")` 判桥接函数。
4. **跨进程服务不能返回 LuaObjectAdapter**：app 进程实例的服务（跨进程代理）返回 Lua 对象会失败。
   → 需要返回 Java 对象的域服务必须在 **Lua 所在进程本地注册**（root 进程 Server.kt / 沙箱 LuaEngineExecutor）。
5. **addLocalService 第三参必须是 interface**：传具体类会让 root 进程 Server.init 的 `Proxy.newProxyInstance` 抛 IllegalArgumentException 启动即崩（"is not an interface"）。
   → 新服务拆 `IXxx` 接口 + `XxxLib` 实现；CLASS 型重载历史上漏赋 mInterface 的 bug 已修，回归时留意 `mInterface!!` NPE。
6. **C++ create() 拦截 ptr==0**：服务包装失败曾导致 NULL lua_State segfault，已加拦截 + loop drop execute 回 Idle——引擎"启动即崩且无 Lua 报错"优先查服务包装链。

## 2. C++/构建体系约束

1. **extension 静态库 JNI 导出必须 whole-archive**：SharedFrame/VisionBridge 无 C++ 调用者，普通静态链被丢弃 → UnsatisfiedLinkError。已在 CMakeLists 固定。
2. **新全局 Lua 库放 base 还是 extension**：base 先链、extension 后链且**反向引用不了 base 新增符号**；base 目录无 lua.hpp，用 `extern "C"` 引 lua.h/lauxlib.h/lualib.h（参照 thread_lib.cpp）。cv_lib 放 base 即此原因。
3. **可选参数判型**：C++ 侧 `L.type(i)` 判型 + `L.top`（属性）判存在性；不要直接 `tostring/toInteger`。
4. **images.fromData 的 stride 参数 = 每像素字节数（3/4），不是行字节数**。
5. **兼容性注册顺序**：compat 必须在所有域服务之后注册（依赖 http/file/crypt/device/app/luajava）；Java 侧 `postNativeInject`（compat 注入）必须在 C++ 图色注入之后执行（否则 compat 包装捕获到 nil）。
6. **共享内存 9 字节自描述头**（bufferIndex/w/h）：布局预留不足会覆盖像素前 9 字节 → "Buffer not large enough for pixels"。
7. **api23+ ACTION 常量不在主类**：AccessibilityNodeInfo 的 ACTION_SCROLL_UP/CONTEXT_CLICK/SHOW_ON_SCREEN/PAGE_*/IME_ENTER 等是嵌套类 AccessibilityAction 的静态实例（取 `.id`），android.jar 主类 int 常量不存在——**不要内联网上查到的 hex 值**（0x20000 实际是 ACTION_SET_SELECTION）。
8. **事件轮询模型（ws/异步）**：回调只入队、Lua 端 poll 拉取；服务端 stop/join 必须不持 recursive_mutex（hv 线程 onclose 再入锁死锁）；客户端回调捕 weak_ptr 防析构竞态。

## 3. 运行时陷阱（联调排障）

1. **杀残留 root daemon 再启动**：杀过引擎进程或重装 APK 后，残留 app_process64 daemon 占 UiAutomation 注册位 → **16 组节点域全 FAIL 且 err 为空串**（= Java 异常无 message）。
   → 跑测前：`ps -A | grep app_process64` 全 kill。
2. **模拟器静止屏幕不出帧**：MediaProjection/镜像在无变化时不合成新帧 → 滑动触发或 stream_sync 强制刷帧；图色相关自测先动一下屏幕。
3. **重装 APK 后 adb forward 竞态失效**：需要重设 forward。
4. **thread/timer 偶发抖动（已修）**：ThreadLib start 已两阶段化（C 先 begin() 登记 taskId → 注册映射 → submit 驱动）；老实现池线程复用时 nativeResume 抢先查不到 co → 任务瞬死。finish() 不自删 tasks、CANCELLED 分支不重复 unref——回归时勿简化。
5. **run_script print 幂等**：主引擎 Lua state 跨 execute 保留，脚本每次 `local __p = print` 会层层叠加包装 → 已把原始 print 存全局 `__ide_orig_print`，包装前恢复再包装。脚本里**不要**再自行重定义 print。
6. **LuaObjectAdapter 适配器自测**：`sel:click()` 能调 ≠ `nd:click()` 能调（入口不同：sel 便捷动作是 Kotlin 方法，节点动作走 index/call 闸门）——两类都要测。
7. **老调试通道已退役**：8176 端口 DebugServiceImp/DebugServerImp 代码保留但 Manifest 已摘除，勿再对接；一切走 8080 WS IDE。
8. **C++ 栈上持有锁/资源时调 `lua_error` = longjmp 跳过 RAII 析构**（NDK Lua 未启用 -fexceptions）：lSleep 曾因 interrupt 挂起点抛 error 未显式 unlock，`signalEvent_` 互斥锁永久泄漏 → loop 线程死锁 → **stop_script 后一切 run_script 静默失败**（"restart-first 部署必重启 app"掩盖多年，270172d 修复）。任何"栈上 C++ 锁/资源 + lua_error 可能传播（含 Lua 回调内）"的代码必须抛错前显式释放；详见 features/runtime/contracts.md §4。
9. **stop_script 的终止语义**：interrupt 只是置标志，脚本在 **sleep 挂起点**抛 `error("interrupt")` 才真正终止——脚本内 `pcall(sleep)` 会吞掉终止信号（cloud.run 泵曾中招：sleep 必须裸调，回调 pcall 后需重抛 interrupt/exitScript）。run_script 默认非 retain：**每次运行后 LuaState 销毁重建**（Lua 层全局随容器隔离；跨层资源回收走 ScriptContextLifecycleListener，见 features/runtime/）。

## 4. 已知限制（有意为之或暂缓）

| 项 | 现状 |
|---|---|
| OCR/YOLO 真实算法 | 不内置；走插件方案（IPlugin/IOcrPlugin + DexClassLoader + so 解压加载），等算法包。demo-ocr 为 mock |

| 悬浮窗权限 | 模拟器需 `adb shell appops set com.autolua.autolua2 SYSTEM_ALERT_WINDOW allow`，否则 addView 抛 BadTokenException（FloatWin 静默吞掉、Dialog 直接抛） |

| fhttp 异步族 | thread 协程内 Java 阻塞请求会卡 worker，异常透传为 "push java throwable error"（已文档标注，自测降级 INFO） |

| root daemon 常驻 | 二期方案（当前每次拉起 app_process） |
| NEON/OpenMP 找图优化 | 未做（性能优化清单见 INTEGRATION_PLAN §9） |
