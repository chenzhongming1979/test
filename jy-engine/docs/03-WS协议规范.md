# IDE WebSocket 协议参考

> 文档版本：v1.1（2026-09-18，三层化重组：命令/消息计数按 WsProtocol.java 实测修正为 33/17，补 §3 stream_sync_result 漏项；域内实现契约下放 features/ide-remote/contracts.md）
> 权威常量源：`engine\src\main\java\com\autolua\engine\ide\WsProtocol.java`（CMD_* 33 个 :42-:156、MSG_* 17 个 :19-:158）；客户端镜像：`vscode-plugin\src\protocol.ts`。
> Handler 注册集中处：`IdeServerManager.registerBuiltinHandlers()`（IdeServerManager.java:223-241）。

## 1. 连接与发现

| 项 | 值 |
|---|---|
| WS 端口 | 首选 **8080**，被占依次回退 8081..8085（IdeServerManager 启动逻辑） |
| UDP 发现 | 广播问句 `AutoLuaEngine,Where are you?` → 应答 `AutoLuaKit,I am here!`（端口 8080..8085；开关随 IdeServerManager 生命周期，DiscoveryManager） |
| adb 场景 | `adb forward tcp:<local> tcp:8080..8085` 后连 `ws://127.0.0.1:<local>`；**APK 重装后 forward 偶发失效需重设** |
| 会话语义 | 帧统一 `{"type":"<cmd>","data":{...}}` JSON 文本帧；**无请求 id**，客户端按 type 配对回包，串行队列发送；单命令超时 15s；心跳 30s |
| 二进制帧 | 同连接混传：投屏 JPEG/H264 数据、`[IMG]` 分片图（ImageChunkAssembler 组装） |

## 3. 设备 → 客户端消息（17 个，与 WsProtocol.java MSG_* 一一对应）

| type | 说明 |
|---|---|
| `hello` | 连接建立握手 |
| `result` / `error` | 通用命令结果 / 错误（error 带异常消息） |
| `pong` | 心跳应答 |
| `push_result` / `delete_result` | 文件推送/删除结果 |
| `log` | 脚本 print 回传（root 走 IdeLog 跨进程代理 → 转发） |
| `image` | 图色命令附带的 [IMG] 分片图像（ImageChunkAssembler 组装） |
| `capabilities` | 能力位回包 |
| `stream_started` | 投屏会话建立确认（首个二进制帧含 avcC/JPEG 头） |
| `stream_sync_result` | `stream_sync` 强制刷帧的回执（WsProtocol.java:128；当前 vscode protocol.ts 未镜像，仅 tools\remote.html 消费） |
| `stream_rotate` | 屏幕旋转，客户端应准备重建解码器 |
| `inject_result` | 注入命令结果（成功 bool） |
| `script_started` | 主引擎脚本启动 |
| `script_state` | `{state:"running"|"idle"}` 广播（脚本启停统一信号，悬浮球/插件按钮状态合一） |
| `ui_debug_result` | UI 热重载启停结果 |
| `plugin_result` | 插件命令结果 |

## 4. 二进制流格式

- **JPEG 模式**：每帧独立 JPEG，直接喂 `ImageDecoder`/`createImageBitmap`。
- **H264 模式**：MediaCodec AnnexB→AVCC 转换后下发；首帧为配置帧（SPS/PPS，avcC 结构），WebCodecs `VideoDecoder` 用 `description` 初始化；NALU type 序列可用 `tools\h264_probe.mjs` dump 分析。
- 投屏码控三参数：fps / bitrate / scale（ScreenStreamController）；**模拟器静止屏幕不合成新帧**，需滑动或 `stream_sync` 强制刷帧。
