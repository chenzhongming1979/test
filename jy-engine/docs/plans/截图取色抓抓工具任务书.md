# 截图取色抓抓工具（独立桌面版）任务书

> 域：[features/ide-remote](../features/ide-remote/README.md)　状态：✅ 已完成（2026-09-23 实测，见 §6）
> 工具源码：`autolua2\tools\capture_tool.py`（新，单文件 Python）　插件：`autolua2\vscode-plugin\`

## 1. 背景与目标

参考懒人精灵/按键精灵"抓抓"软件，开发 PC 端截图取色工具，辅助脚本作者制作找色/找图特征。引擎侧图色基建已齐备（jpeg 单帧截图、`cmp_color`/`find_multi_color`/`find_image`/`ocr` 四个 IDE 命令、`capabilities` 能力探测），缺的只是交互面板。开源参考：AirtestIDE（截图→框选模板→验证工作流）、scrcpy（投屏，仅交互参考）。

设计决策（用户已拍板）：
- **独立桌面窗口**，Python Tkinter 单文件（`capture_tool.py`），不做 webview/浏览器页面；工具自行连接模拟器，VSCode 插件只加按钮调起
- **单帧截图取色**，不做实时投屏（`stream_start(jpeg)` 抓一帧即 `stream_stop`）
- 一期功能：单点+多点取色（多点首点=锚点）、框选截图存模板 PNG、四命令一键实机验证、OCR 区域取词
- **代码生成**：默认生成引擎 Lua API 片段，模板占位符可自定义——用户可提取坐标/颜色等值自行拼接
- 通道共存已论证（不与插件争抢）：adb forward 规则可并存（工具用独立本地端口段 18090-18095）；`IdeWebSocketServer` 为多客户端广播模型（lastSeen Map 按 clientId 跟踪）；工具只发只读命令（截图/图色/OCR），不碰 run_script 运行态

## 2. 协议契约（全部复用现有命令，引擎零改动）

### 2.1 连接
- 端口 8080 失败回退 8081-8085；连上后服务器主动推 `hello {clientId,device_name,app_version}`
- 心跳：客户端每 ≤30s 发应用层 `ping`（回 `pong`），否则 75s 被踢（close 4001）
- adb 模式：`adb -s <serial> forward tcp:1809N tcp:808N` 逐端口探测 → `ws://127.0.0.1:1809N`；直连模式：`ws://<ip>:808N`

### 2.2 单帧截图
`stream_start {codec:"jpeg",fps:1,quality:80,scale:1.0}` → `stream_started {w,h}` → 二进制帧（16 字节大端头 `[4B seq][4B w][4B h][4B len][jpeg字节]`）→ `stream_stop {}`。首帧典型 <1-2s；静止画面引擎会回退喂共享内存最后一帧。

### 2.3 图色命令（similarity 默认 0.9，映射每通道最大绝对差 (1-s)*255；颜色支持 0x/hex/十进制；rect {x,y,w,h} 可选）
| 命令 | 请求 data | 回包 data |
|---|---|---|
| cmp_color | `{points:[{x,y,color}],similarity?,rect?}` | `{"match":bool}` |
| find_multi_color | `{points:[...首点锚点，其余为相对锚点偏移校验点(发绝对坐标)],similarity?,rect?}` | `{"found":bool,"points":[{x,y}...]}` |
| find_image | `{templateBase64,threshold?,rect?}` | `{"found":bool,"x","y","similarity"}` |
| ocr | `{rect?}` | `{"results":[{text,x,y,w,h,confidence}],"text"}`（需 ncnn-ocr 插件，capabilities.vision.ocr 运行时判定） |

采集管线说明：root 模式 `stream_start` 内部 `prepare()` 启动 VirtualDisplay 持续产帧，`stream_stop` 只释放编码器，共享内存保留最后帧 → 抓单帧后图色命令仍可用（`FrameBuffer.getLatestFrame(false,ttl)` 陈旧帧兜底回缓存）。

已知边界（实测结论）：
- **模板/色值的来源差**：工具侧取色与模板截图来自 **JPEG 流解码帧**，引擎图色命令比对的是**原始 RGBA 帧**——高饱和边缘像素经 4:2:0 色度抽样后偏差可达 20+/通道。对策：相似度默认 0.9（每通道容差 25）；取色尽量选平坦色块（放大镜可辅助判断）；找图模板选纹理适中区域，纯色/高频边缘模板需调低 threshold。
- **引擎修复（随本任务书）**：`VisionBridge.cpp` ①`nativeFindMultiColor` 原先只校验**首个**锚点候选，锚点为白/黑等常见色时大面积假阴性 → 改为锚点候选全扫描（对齐 Java 回退语义）；②`nativeFindImage` 验证像素预算 20M 在 C++ 内核下过保守（模板首像素为常见色时锚点预筛选通过率极高，全屏搜索未达即预算耗尽假阴性）→ 放宽至 2G（病态最坏 2~4s）。

### 2.4 代码生成依据（docs/02-Lua-API规范.md §2）
`cmpColor(x,y,color,sim)` / `isColor(x,y,color,sim)`、`findColor(x1,y1,x2,y2,color,sim[,order])`、`findMultiColor(x1,y1,x2,y2,firstColor,offsetStr,sim)`（offsetStr=`"dx|dy|色,dx|dy|色,..."` 首点相对坐标）、`findImage(img,sim[,order])`（img 为路径字符串或 loadImage Bitmap）、`getColor(x,y)`、`keepScreen()/updateScreen()`。

## 3. 实现清单

### 3.1 capture_tool.py 单文件结构（预算 ~1200 行，分批写入）
| 段 | 内容 |
|---|---|
| 常量与配置 | 端口段 8080-8085 / 本地 forward 段 18090-18095；`capture_config.json`（同目录，存上次连接方式/serial/IP/adb 路径/相似度/模板目录）持久化 |
| WsClient 类 | websocket-client 收发线程 + queue + `root.after(50)` 轮询；按 type 排队等待回包（无 callId，串行）；25s 心跳；hello/capabilities 事件回调 |
| 连接管理 | adb 模式（`subprocess` 枚举 `adb devices` → forward + 端口探测）与直连模式；状态栏显示 device_name/app_version/分辨率/OCR 可用性 |
| 截图 | stream_start→收首帧（解析 16B 头，超时 10s 报错）→stream_stop→PIL 显示；保留 PIL Image + 屏幕绝对坐标换算（画布缩放比） |
| 画布交互 | 缩放适配显示；鼠标移动→放大镜（21x21 crop → NEAREST 放大 + 十字线 + 中心点 hex/dec 实时显示）；点击取色（单点/多点模式，多点首点=锚点，右键撤销）；拖拽框选（矩形覆盖层） |
| 取色点列表 | Treeview（#、类型 锚点/偏移、绝对坐标、hex、相对偏移 dx,dy）+ 删除/清空 |
| 验证 | 多点验证→find_multi_color（锚点+偏移自动生成 points）；比色验证→cmp_color；找图验证→find_image（框选模板 templateBase64）；OCR→ocr(rect)；结果画标记/框 + 文本块列表 |
| 代码生成模板 | 占位符表（§3.2）；`capture_templates.json` 同目录持久化，UI 可编辑保存；生成结果 Text + 复制按钮 |

### 3.2 代码生成占位符与默认模板
| 占位符 | 含义 |
|---|---|
| {x1} {y1} {x2} {y2} | 搜索区域（默认整屏，有框选则用框选） |
| {x} {y} | 单点坐标（单点模式） |
| {color} {firstColor} | 颜色 0xRRGGBB（单点 / 锚点） |
| {offsetStr} | 懒人格式偏移串 `"dx|dy|色,dx|dy|色,..."`（不含锚点自身） |
| {sim} | 相似度 |
| {img} | 模板图路径 |
| {rect_json} | 框选区域 JSON `{"x":..,"y":..,"w":..,"h":..}` |
| {ocr_text} {ocr_json} | OCR 全文 / 文本块 JSON |

默认模板（可改，{name} 逐个 replace，不做 format 防花括号冲突）：
- 多点找色：`local x, y = findMultiColor({x1}, {y1}, {x2}, {y2}, {firstColor}, "{offsetStr}", {sim})`
- 单点比色：`local ok = cmpColor({x}, {y}, {color}, {sim})`
- 区域找图：`local ix, iy = findImage("{img}", {sim})`
- OCR：输出引擎命令参数 JSON（Lua 侧 OCR API 未定型，模板留给用户自定义）
