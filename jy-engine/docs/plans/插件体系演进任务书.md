- 框架稳定：zip 包 + manifest sha256 强校验 + DexClassLoader + so 解压（[../features/plugins/contracts.md](../features/plugins/contracts.md)）。

- 签名：`autolua2\plugins\sign-plugin.ps1` + `signing\dev-key.json` 已备；宿主校验未接线。

## 2. 真机联调（P0）

- 范围：demo-ocr / ncnn-ocr / demo-luaapi 在真机完成 安装→OCR 识别→覆盖重装（.tmp/.old 原子交换，验证同进程 so 仅落盘不热重载语义）→卸载 全链路。
