## 2. 引擎 execute 偶发挂死排查（P0）

- 现象：`run_script` 偶发 `script_started` 后无任何输出、不回 idle；复跑丢输出已用纯 print 脚本佐证，与 UI 无关（06 §4 表）。
- 排查方向：① worker 状态机 ALEState 停留态（`autolua2\engine\src\main\cpp\core\ALEState.h`）；② execute 信号链 kInterrupt/kResume 抵消语义（[../features/engine-core/contracts.md](../features/engine-core/contracts.md) §2）；③ root RPC TransportImp 读写线程竞态（[../features/ipc/contracts.md](../features/ipc/contracts.md) §1）。
- 验收：复现脚本 100 连跑无挂死；或定位根因修复并留回归用例进 `autolua2\tools\selftest\`。

## 3. Lua 断点调试迁移 WS 协议（debug_attach/breakpoint，P1）

- 背景：老 8176 调试通道已退役（06 §3 第 7 条），断点能力未迁移。
- 方向：在 03-WS协议规范.md §2 新增命令族（须同步 `WsProtocol.java` CMD_* 与 `vscode-plugin\src\protocol.ts` 双端）；C++ 侧挂 `lua_sethook`（`autolua2\engine\src\main\cpp\core\LuaInterpreter.cc`），断点事件走 MSG_* 回帧。
- 验收：VSCode 插件可下断点、单步、查看栈变量；全量自测无回归。
