## 2. 契约（实现必须严格对齐 contracts.md §4）

### 状态机
```
unauth →(auth op 成功)→ authorized ──(心跳失败≥fail_limit 或 expire 到期)→ expired
      →(login 失败)→ denied（允许重新 auth）
```
- 授权信息存 `cloud.state.auth = {status, token, expire, provider, card}`
- 拦截矩阵：ping/state/debug/stop 放行；sync/init/pageTest/taskTest/action/scriptRun 未授权返回 `{ok:false, msg:"未授权(先 auth)"}`

### Provider 契约（auth_provider.lua，作者实现）
```lua
local M = {}
function M.login(card, device)   -- → true, token, expireTs(os.time 秒) | false, 原因
function M.heartbeat(token)      -- → true, remainSeconds | false, 原因
function M.logout(token) end     -- 可选
return M
```

### auth 配置（cloud.conf.auth，可经 sync 下发覆盖）
```json
{"provider":"custom","module":"auth_provider","heartbeat_interval":300,"fail_limit":3}
```
- `provider="custom"`：dofile `DIR/<module>.lua`（require 劫持已覆盖任意名字，直接 dofile 即可）
- `provider="builtin"`：白名单测试——白名单来自 `cloud.conf.auth.cards`（数组），login 命中即授权（expire=now+3600），heartbeat 恒真
- 未配置 auth 时**不拦截**（保持向后兼容，本地调试态）

### 协议
```
请求：{"op":"auth","card":"xxx"}
响应：{ok, state:{auth:{status, expire, remain}}}
心跳：poll 循环内每 heartbeat_interval 秒调 provider.heartbeat；
      失败连续 fail_limit 次 → status=expired → 停止执行类 op（已执行的不管）
```
