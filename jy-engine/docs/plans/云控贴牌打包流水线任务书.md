# 云控贴牌打包流水线（brand.json）任务书

> 域：[features/cloud](../features/cloud/README.md)　状态：✅ 已执行并实测通过（Phase A，2026-09-20）
> 工程位置：引擎 `d:\...\jy-frame-lrjl\jy-frame-engine\autolua2\`（app 源码）+ 脚本工程 `D:\Project\script\lrjl\engine\`（pack.py）

## 1. 背景与目标

脚本作者需要把云控框架打包成**自有品牌 APK** 交付客户：自定义 app 名称/图标/包名，且 APK 内置云控壳工程（首启自动导入，客户无需手动导入 zip）。

目标：
1. 构建参数化：包名/app 名称经 gradle `-P` 参数注入，默认值保持现状（不回归）
2. assets 自动导入：APK 内置 `brand_assets/brand/`（brand.json + 工程 zip），MainApp 启动自动导入为引擎工程
3. pack.py：作者填 `brand.json` 一键出品牌 APK（含图标替换）
4. 模拟器端到端验证：安装定制 APK → 品牌生效 → 工程自动导入 → 云控可连

## 3. 实现清单

### 3.1 build.gradle.kts 参数化（源码树一次性改造）
```kotlin
// android{} defaultConfig 内：
val brandAppId = (project.findProperty("BRAND_APPID") as String?) ?: "com.autolua.autolua2"
val brandName  = (project.findProperty("BRAND_NAME")  as String?) ?: "autolua2"
applicationId = brandAppId
resValue("string", "app_name", brandName)
```
- **必须删除** strings.xml 里的 app_name 行（否则与 resValue duplicate resource 冲突）
- sourceSets main 增加 `assets.srcDir(rootProject.file("brand_assets"))`（brand_assets 目录由 pack.py 生成，进 APK；加入 .gitignore）
- 输出名：有 BRAND_NAME 时改为 `"${brandName}_${variant.versionName}.apk"`
- manifest/namespace 不动

### 3.2 MainApp assets 自动导入（源码一次性）
MainApp.onCreate 中 ProjectManagerImp.init 之后：
```kotlin
assets.list("brand")?.filter { it.endsWith(".zip") }?.forEach { zip ->
    ProjectManagerImp.instance.addProject(zip.removeSuffix(".zip"),
        assets.open("brand/$zip").readBytes())
}
```
- 同时把 `assets/brand/brand.json` 释放到导入工程的根目录（Lua 侧读 cloud_url）——导入是异步队列，直接在 addProject 投递后向 `File(sdCardDir+"project", projectName)` 写入有竞态；**实现选型**：把 brand.json 的内容在 pack.py 阶段直接打进工程 zip 内（zip 根 brand.json），MainApp 只投 zip → Lua 从 DIR/brand.json 读 ✓（推荐，免竞态）
- addProject 投队列线程安全（loopHandleTask 消费），重复导入同 version 覆盖 ✓

### 3.3 main.lua 读 brand.json
启动时若 `DIR/brand.json` 存在：解析并打印品牌信息（app_name/cloud_url）；`cloud_url` 存在时打印 `云控地址:`（v1 保持设备端 server 9300 模式，client 反连模式不在本任务）。

### 3.4 pack.py（作者工具，`D:\Project\script\lrjl\engine\pack.py`）
```
用法：python pack.py --brand brand.json [--out dist]
brand.json：
{
  "app_name": "云控助手",
  "package_name": "com.test.cloudassist",
  "icon": "./icon.png",                     // png，转存为 mipmap-hdpi/logo.jpg
  "project_zip": "./jyframe-cloud.zip",     // 云控壳工程（含 package.json + brand.json）
}
流程：
 1. 校验：包名正则 ^[a-z][a-z0-9_]*(\.[a-z0-9_]+)+$；icon/zip 存在；zip 根有 package.json（缺则自动注入 {"name":"jyframe-cloud","version":"v1.0"}）与 brand.json（cloud_url 透传）
 2. 生成 brand_assets：autolua2/brand_assets/brand/{project.zip 重命名, brand.json}
 3. 图标替换：icon → app/src/main/res/mipmap-hdpi/logo.jpg（先备份）
 4. 构建：cd autolua2 && .\gradlew.bat assembleDebug -PBRAND_APPID=.. -PBRAND_NAME=..
 5. 产物复制为 dist/<app_name>.apk；还原 logo.jpg；清理 brand_assets
```

### 3.5 测试工程 zip 打包（pack.py 顺带或独立 build_zip.py）
把 `engine\` 的 main/cloud/Funs.lua + frameSdk-autolua2/ + JY/（源 d:\...\jy-frame-firefly\脚本\JY）打 zip，注入 package.json + brand.json —— 供 project_zip 用。
